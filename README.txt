# 座席区画④WEBアプリ

## ファイル
- `index.html` : 座席表本体
- `manifest.webmanifest` : ホーム画面追加用の設定
- `sw.js` : オフライン表示用
- `icon-192.png`, `icon-512.png` : アプリアイコン

## 公開方法（GitHub Pages）
1. GitHubにサインインし、新しいPublicリポジトリを作成（例: `seatmap-kaku4`）。
2. このZIPを解凍し、中の5ファイルをリポジトリの一番上の階層にアップロードする。
3. リポジトリの Settings → Pages を開く。
4. Build and deployment の Source を `Deploy from a branch` にし、Branch を `main`、フォルダを `/(root)` にして Save。
5. 公開完了後に表示される `https://ユーザー名.github.io/seatmap-kaku4/` をiPhoneのSafariで開く。

## iPhoneでホーム画面に追加
1. Safariで公開URLを開く（アプリ内ブラウザではなくSafari）。
2. 共有ボタン（四角から上矢印）をタップ。
3. 「ホーム画面に追加」を選ぶ。
4. 必要に応じて「Webアプリとして開く」をオンにして「追加」。

## 使い方と保存
- 「塗り潰す」を選んで座席をタップすると黄色の「使用」になる。
- 「元に戻す」を選んで座席をタップすると白い「空席」に戻る。
- 使用席・空席は自動集計される。
- 状態はそのiPhoneのSafari内に保存され、同じ端末・同じブラウザで使う限り再表示後も残る。
- 他の人や別端末との同期機能はありません。
- SafariのWebサイトデータ削除やプライベートブラウズでは保存が失われる可能性があります。

## 座席設定
16行×8列、座席番号24〜31。4行目の27番・28番は使用不可。使用可能席は126席。


【今回の追加機能】
・「座席表」と「出席人数カウント」を画面上部の切り替えボタンで移動できます。
・空席カウント画面の大きな青いボタンを押すと空席数が1増えます。
・出席人数は「126－空席カウント」で自動計算します。
・「1つ戻す」と「リセット」を用意しています。
・空席カウントは座席表の使用／空席の色分けとは独立してiPhone内に保存されます。
・上限は126席です。
・更新版ではキャッシュのバージョンも更新しています。
